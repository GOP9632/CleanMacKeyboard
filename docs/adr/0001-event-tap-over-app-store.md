# 用系統事件攔截實作，放棄 App Store 上架

Wipe 的核心功能是在清潔模式期間丟棄鍵盤與觸控板事件，在 macOS 上這只能透過 CGEventTap 搭配「輔助使用」授權完成。App Store 要求 app 執行於沙盒，而沙盒禁止這個等級的輸入攔截，兩者無法並存。我們選擇保留功能、放棄上架，分發方式限定為直接下載。

這不是技術難度問題，是規則直接排除。未來若有人提議上架，答案不會因為多寫程式而改變，除非 Apple 改變沙盒政策。

## Consequences

- 專案的 `ENABLE_APP_SANDBOX` 必須維持 `NO`。任何「順手把沙盒打開」的整理都會讓 app 直接失去功能。
- 分發需要穩定的簽章身分。目前純自用，之後若要給別人用需要 Developer ID 加公證。
- 「輔助使用」授權是綁在 app 的簽章上的。更換 bundle ID 或簽章身分會讓使用者必須重新授權。
